# Maya Chen portfolio

This project is a root-level static Jekyll portfolio designed for GitHub Pages.

## Where things live

- Markdown pages: `index.md`, `about.md`, `work.md`, `contact.md`
- Shared HTML: `_layouts/` and `_includes/`
- Styles and theme toggle: `assets/css/style.css` and `assets/js/site.js`
- GitHub Pages config: `_config.yml`

## Publishing

Publish the `main` branch from `/ (root)` in GitHub Pages. The site is configured with an empty `baseurl` for a GitHub user site.

## Notes

The content is fictional sample copy and should be replaced before publishing. See `README.md` for editing, local preview, and Lighthouse instructions.
