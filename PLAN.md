# Site plan

This is a small, publish-ready GitHub Pages portfolio for a fictional product designer and front-end developer, Maya Chen (`mayachen.github.io`).

- **Pages:** Home, About, Work, and Contact, all written in Markdown with YAML front matter.
- **Design:** A responsive single-column system with warm paper tones, deep ink, orange accents, clear typography, and an optional light/dark theme toggle.
- **Technical approach:** Jekyll layouts and includes keep shared structure reusable while page content stays in Markdown. SEO tags, sitemap, favicon, semantic HTML, accessible focus states, and reduced-motion support are included.
- **Hosting:** GitHub Pages from `main` and `/ (root)` with an empty `baseurl`, matching a GitHub user site.

## Assumptions

The person, GitHub username, email, social profiles, project names, and work history are fictional placeholders. Replace these details before publishing.
